矩形を塗る手

画面のすべてが、CPU の一バイトずつの手紙で描かれるわけではない。塗る手は、矩形をまとめて引き受ける。 "Not every pixel is a letter from the CPU. The painter accepts a rectangle whole."
← 表紙の二枚へ戻る
01 / Hands

1. 持っている筆

点 · 線 · 矩形 · CPU からの転送

歩かせる筆は、止める、一点を読む、一点を書く、線を Bresenham で引く、色で矩形を塗る、矩形を別の場所から写す、CPU から画素を受け取る、CPU からバイトを受け取る、バイトで塗る、バイトで写す、Y 方向へ写す、の十一である。論理は、新しい色をそのまま書くものに加え、AND、OR、XOR、NOT、そして新しい色が 0 のとき古い画素を残す TIMP、TAND、TOR、TXOR、TNOT がある。TIMP は、新しい色が 0 でなければ新しい色、0 なら古い画素である。画面 8 と画面 7 では横 256 バイトが 1 行、画面 5 と画面 6 では 128 バイトである。縦は 10 ビットのまま番地に入り、128 KB で折り返さない。Y が 512 の裏の頁にも、Y が 724 のフォントにも届く。幅か高さが 0 のとき、幅は行の長さ、高さは 1023 として歩き始める。 "Eleven brushes actually walk: stop, read a point, write a point, a Bresenham line, a rectangle of one color, a rectangle copied from elsewhere, pixels from the CPU, bytes from the CPU, a byte fill, a byte copy, and a vertical copy. The logical ops are replace, AND, OR, XOR, NOT, and the transparent forms TIMP, TAND, TOR, TXOR, and TNOT, which keep the old pixel when the new color is zero. TIMP writes the new color unless that color is zero. Screen 8 and screen 7 use 256 bytes on a row. Screen 5 and screen 6 use 128. The vertical coordinate enters the address as ten bits and does not fold at 128 KB, so Y of 512 and Y of 724 are both reachable. A width or height of zero starts the walk at the row length, or at 1023 lines."
02 / Copy

2. 写す筆は、先に読む

LMMM · 題字は別の道 · ロゴは HMMC

矩形を写す筆は、色レジスタでは塗らない。先にソースの画素を読み、それをインクにしてからディスティネーションへ書く。ソースの番地は、画面 8 では行き先と同じ式である。書き終えたら次のソースを読みに戻る。色で塗る筆だけが、読みを省略して色レジスタから始める。C-BIOS のロゴは、CPU からバイトを渡す筆を使う。その筆は、ロゴが今も描ける形のまま残してある。座標の幅は C の参照と同じで、横の上位は 9 ビット、縦と幅と高さの上位は 10 ビットである。 "The copying brush does not paint from the color register. It reads the source pixel first and uses that as ink. On screen 8 the source address uses the same formula as the destination. After the write it goes back for the next source. Only the solid-color brush skips the read and starts from the color register. The C-BIOS logo uses the brush that accepts bytes from the CPU, and that brush is left in the shape that still draws the logo. Coordinate widths match the C reference: the high bit of X is nine bits wide, and the high part of Y, width, and height is ten."
表紙の題字の本体は、CPU がポート $98 へ書いた VRAM を、前の章の 256 色が色にしたものである。C-BIOS のロゴが使うバイト転送は、上の段に書いたとおり、ロゴが描ける形のまま残してある。 "The body of the title on the cover is VRAM the CPU wrote through port $98, colored by the 256-color table. The byte transfer the C-BIOS logo uses is the one named above, left in the shape that still draws the logo."
NOTE: SRCH と LMCM は番号だけがある。理由は、開始の分岐がどちらも歩かせず、終了へ送ること。 "NOTE: SRCH and LMCM exist as numbers only. The start of the walk sends both of them to the end, and neither takes a step."
NOTE: 題字の下の帯は、この筆が届いていない。理由は、一色の矩形とフォントからの写しが、キャプチャの終わるまでに発行されず、y が 175 以降がまだ絵の続きであること。筆そのものは、その命令を受ければ歩ける。 "NOTE: the band under the title has not been reached by these brushes. The solid rectangle and the copy from the font have not been issued when the capture ends, so the rows from y 175 on are still the picture. The brushes themselves can walk once those commands arrive."
