サンプルの息

ターボ R が笛でも波でもない声を出すとき、それは 0 から 255 の一本のサンプルである。真ん中の 128 が、沈黙である。 "When the turbo R speaks in a voice that is neither pipe nor wave, it is one sample from 0 to 255. The middle, 128, is silence."

01 / Breath

1. $A4 にサンプル、$A5 に作法

ラッチするか、近づくか

ポート $A4 へ書いた 8 ビットが、次に出したい高さである。$A5 のビット 0 が立っていれば、次の息でその高さをぴたりと掴む。ビット 0 が下りていれば、現在の高さから一歩に 48 までしか近づかない。ビット 1 は、DAC そのものを生かすかである。朝の制御は 0x03 で、掴む方と DAC の両方が有効、朝のサンプルは 0x80 の沈黙である。$A4 を読むと息のカウンタの下位 2 ビットが返り、相手はそれで手渡しを知る。$A5 の読出は、制御の下位 5 ビットである。 "The eight bits written to port $A4 are the next height. If bit 0 of $A5 is up, the next breath takes that height exactly. If bit 0 is down, the current height may approach it by at most 48 in one breath. Bit 1 enables the DAC itself. The morning control is 0x03, so both the exact take and the DAC are on, and the morning sample is the silence at 0x80. Reading $A4 returns the low two bits of the breath counter, which is how the other side knows the handoff. Reading $A5 returns the low five bits of the control."
02 / Queue

2. 228 歩に一度

書込は列に置き、息の規則と喧嘩しない

息は Z80 の 228 歩に一度、およそ 15.7 kHz である。CPU の書込は一度列に置き、息の規則と同じレジスタを同じ拍で奪い合わない。近づく計算のためのレジスタは 9 ビットで、符号が収まる。朝の高さは 128、沈黙の 0x80 である。表紙の二枚は、キーを待たずに止めた絵であり、この声のサンプルもその枚には載せていない。 "A breath is once every 228 Z80 steps, about 15.7 kHz. A write from the CPU waits in a queue, so it does not seize the same registers as the breath in one beat. The register used while approaching is nine bits wide, enough for a sign. The morning height is 128, the silence at 0x80. The two plates on the cover were stopped without waiting for a key, and those frames do not carry a sample of this voice."
NOTE: この息を参照機と突き合わせた記録は無い。理由は、頁に残した走行が絵だけで、PCM のサンプル列を残していないこと。 "NOTE: there is no comparison of this breath against a reference machine. The runs kept on the page are pictures, and they did not keep a PCM sample stream."
