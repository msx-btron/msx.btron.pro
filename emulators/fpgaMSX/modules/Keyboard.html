十一行の鍵盤

MSX の鍵は、押すと線が下りる。沈黙は、すべてのビットが 1 のままの行列である。 "An MSX key pulls its line down. Silence is a matrix in which every bit is still a one."
← 表紙の二枚へ戻る
01 / Matrix

1. 十一行だけを覚えている

行 11 以降は 0xFF

覚えている行は十一。各行 8 ビット、朝はすべて 1。列 0 がビット 0、列 7 がビット 7。ハーネスが鍵を下ろすと、そのビットが 0 になる。鍵を上げると 1 に戻る。十二行目以降を読むと、覚えていないので 0xFF が返る。番のポート C が行を選び、この章がその行をポート B へ返す。 "Eleven rows are remembered, eight bits each, all ones in the morning. Column 0 is bit 0 and column 7 is bit 7. When the harness lowers a key, that bit becomes zero. When the key rises, the bit returns to one. A read of row twelve or beyond is not remembered, and answers 0xFF. Port C of the keeper chooses the row, and this chapter returns that row to port B."
02 / Still

2. 表紙は、鍵を待たなかった

SPACE は、まだ押していない

表紙の二枚、五色のロゴと AUREL VAULT の題字は、どの鍵も下ろさないまま Verilator が止めた絵である。朝の行列はすべて 1 のまま、ポート B は 0xFF を返し続けた。題字の作者表記は題字の側に属する。Solo Game Author は @kanon-ai。ロゴの側の作者表記は、C-BIOS のスプラッシュに属する。 "The two plates, the five-color logo and the AUREL VAULT title, are frames the Verilator stopped with every key still up. The morning matrix stayed all ones, and port B kept answering 0xFF. The author credit belongs with the title. The Solo Game Author is @kanon-ai. The credit on the logo belongs to the C-BIOS splash."
NOTE: 題字の下の「SPACE」は、まだ塗られていない帯の文言である。理由は、その帯が第11章の NOTE にあり、このキャプチャはどの行も押さずに止まっていること。 "NOTE: the SPACE under the title is wording on the band that has not been painted. That band is the note in chapter 11, and this capture stopped with every row still up."
