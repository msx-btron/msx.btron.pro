番地の言葉

この章には記憶が無い。あるのは、機械の住人が互いに渡す手紙の形だけである。 "This chapter has no memory. It is only the shape of the letters the occupants pass to one another."
← 表紙の二枚へ戻る
01 / Letter

1. 手紙

24 ビット · 8 ビット · 誰の声か

手紙には五つの欄がある。誰が書いたか、24 ビットの番地、8 ビットのデータ、書くのか読むのか、それがメモリなのか入出力なのか。返事は短い。同じ札、8 ビット、用意ができたかどうか。物理の窓を決めるのは次々章のスロット係であり、この言葉は窓の意味を知らない。 "A request carries a name, a 24-bit address, eight bits of data, a read or a write, and whether the address is memory or a port. The reply is the same name, eight bits, and a ready flag. The slot keeper, two chapters on, decides what the windows mean. This language does not."
02 / Names

2. 五つの札

CPU · 走査 · コマンド · 空席 · 音

札は五つ用意してある。演算手が 0、画面の走査が 1、コマンドで塗る手が 2、音が 4。番地は 24 ビットで、0x000000 から 0x3FFFFF までを一枚の言葉にする。公式の機械が音を運ぶとき、普段はポートを通り、4 番を DMA としては使わない。 "Five place cards are prepared. The processor is 0, scanout is 1, the command painter is 2, and audio is 4. The address is 24 bits, one language from 0x000000 through 0x3FFFFF. Ordinary sound in this machine travels through ports, and card 4 is not used as DMA."
NOTE: 札 3 は Geo3D の番号として残してある。理由は、そのモジュールの原稿が無く、この言葉が番号だけを持っていること。 "NOTE: card 3 is kept as the Geo3D number. There is no manuscript for that module, so the language has only the number."
