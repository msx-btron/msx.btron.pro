fpgaMSX (Emulators)

C99 コア tronMSX と同じ機械を、Bluespec のレジスタ転送で書き直した MSX turbo R。検証は Verilator 上のヘッドレス実行であり、ビットストリームは焼いていない。 "fpgaMSX, codename bx8, is the Bluespec MSX turbo R beside tronMSX. One master clock, a C99 Verilator harness, and a frame record for every cartridge in the depot. No bitstream has been loaded onto a board."
← 摸擬目録へ戻る (Emulators Index)
シリコンの前に、絵で止める。 — ソースは btron/src/emulators/bx8/ にある。マスタクロックは 57.2727 MHz の一つで、tick_28m、tick_7m、tick_3m58、tick_e6 は同じクロック上のイネーブルである。Z80A と R800 は一つの CPUCore を分け合い、T9769C のポート $E4 / $E5 が切り替える。assets/msx/ の ROM 14 本はすべてカートリッジの初期化番地に到達した。絵になるのはその一部である。 "The machine lives at btron/src/emulators/bx8/. Z80A and R800 share one CPUCore, switched by the T9769C. All fourteen cartridges reach their init vector. The plates below are the frames that actually drew."
01 / Placement

1. 配置 (Where bx8 Sits)

src/emulators/bx8 · Sibling of tronMSX · Proofs in build/bx8

ソフトウェアの MSX と、同じ倉庫の FPGA 機械。
"The C99 reference and the Bluespec machine are siblings. Boot frames stay in the depot build tree; this page keeps display copies."
場所 中身
src/emulators/msx/ tronMSX。確定性 C99。bx8 の参照実装。
src/emulators/bx8/bsv/ Bluespec の SoC。CPU、スロット、V9958、PSG、SCC、PCM、PPI。
src/emulators/bx8/sim/verilator/ C99 ハーネス sim_rom.c と fpga_rom_runner。
src/emulators/bx8/syn/ ULX3S / Tang Primer 20K のラッパと Yosys スクリプト。未焼成。
build/bx8/ 起動証明。PPM、ログ、summary.txt、PNG。ALL_DONE、14 本とも exit 0。
doc/md/FPGA.md 設計メモ。パスは src/emulators/bx8/ を指す。
02 / Silicon

2. 実装されている単位 (Silicon That Is In The Tree)

CPUCore · T9769C · SlotManager · V9958 · PSG · SCC · PCM

ツリーにファイルがあるものだけを載せる。OPLL と Geo3D の BSV は無い。
"Modules listed here have sources. OPLL.bsv and Geo3D.bsv do not exist. ASCII16 bank switching is still a host intercept in the harness."
BSV 対応する C99 いま動いていること
cpu/CPUCore.bsv z80.c / r800.c 一つのレジスタファイル。リセット後は Z80。ポート $E4 のビット 5 が 0 で R800。C-BIOS の wait_b を抜けてカートリッジに入る。
cpu/T9769C.bsv t9769c.c S1990。レジスタ 6 のビット 6 が DRAM シャドウ。リセット値 cpu_status = 0x60。
memory/SlotManager.bsv slots.c スロット 1 は全ページがカートリッジ窓。空のページ 0 は 0xFF のままで、CHKRAM は通る。$FFFF の読出は反転。
memory/Mapper.bsv slots.c 512 KB のマッパ RAM。物理 0x010000、マスク 0x1F。
vdp/V9958.bsv v9938.c SCREEN 5、SCREEN 2（G2）、SCREEN 1（G1）を VRAM からスキャンする。スプライトと SCREEN 0 は未描画。
audio/PSG.bsv SCC.bsv PCM.bsv psg.c scc.c pcm.c 音源の器はある。この頁の記録は絵であり、音の照合はまだ無い。
io/PPI.bsv Keyboard.bsv ppi.c kbd.c PPI $A8 はリセットでスロット 0。キーボード行列はハーネスから押せる。
03 / Map

3. クロックと物理番地 (Clock And Physical Map)

57.2727 MHz · 24-bit Flat Address · C-BIOS turbo R

メモリモデルの初期値は 0xFF。カートリッジ A は 0x100000。
"BIOS, sub-ROM, mapper RAM, two cartridge windows, and VRAM share one 24-bit space. The harness loads C-BIOS turbo R before the cartridge."
物理番地 窓 備考
0x000000 メイン BIOS 32 KB cbios_main_msxtr.rom。リセットは F3 C3 D2 23（DI; JP $23D2）。
0x008000 サブ ROM 16 KB スロット 3-1、ページ 0。
0x010000 マッパ RAM 512 KB スロット 3-0。
0x100000 カートリッジ A CPU $0000 が物理 0x100000、$4000 が 0x104000。16 KB はページ 1 と 2 に鏡写し。48 KB で $4000 に AB がある像はページ 0 から載る。
0x200000 カートリッジ B 第二窓。今回の 14 本は A 側。
0x300000 VRAM SCREEN 2 のネームは $1800、色は $2000、パターンは $0000。
04 / Frames

4. 起動の絵 (Frames That Drew)

MSX_LOGO · YAZZIER · Dynamite Go! Go! · Night Raven

五枚は Verilator が書いた PPM からの PNG である。縦縞はビームが 168 歩で 256 画素を埋めるための補間で、絵の識別はできる。
"Five frames from the archived PPM files. Vertical stripes are the 168-step beam fill. The picture is still the title the cartridge wrote."

起動成功の基準。ランナーは CARTRIDGE BOOT SUCCESS を出し、初期化番地 0x4010 の近くで止まる。五色のロゴ。

「The cracker: Egor」「keyboard type: JP」「No ROM in slot」が読める。末尾の SP はページ 0 に落ちており、割り込み後のスタックは未解決。

20 フレームでは黒のままである。120 フレームで「PROJECT EGG PRESENTS」が出る。下 20 行は 192 ラインの外で黒。

メニューが読める。「ARROWS OR JOYSTICK」「SPACE TO LAUNCH」。14 色。これは VDP のスキャンアウトであり、Geo3D 演算器ではない。

星と星雲と、右の惑星。CPU が VRAM に書いた絵を V9958 が走査している。幾何アクセラレータの BSV は無い。

05 / Record

5. 十四本の起動記録 (Every Cartridge)

assets/msx/*.rom · Exit 0 · CARTRIDGE BOOT SUCCESS

20 フレーム、サイクル上限 2 億。長い四本は 120 フレーム、上限 4 億。build/bx8/frames-20/summary.txt が台帳。
"Every ROM reached its cartridge init vector. A reached vector is not a finished picture. Disk images were not booted."
ROM 載せ方 最後の PC / SP 絵
MSX_LOGO.rom 16 KB、AB、0x4010 0x4075 / 0xF2E8 Z80 五色のロゴ
MSX_LOGO-v2.rom 16 KB、同じ系統 0x4075 / 0xF2E8 Z80 ロゴ
MSX_LOGO-clean-final.rom 16 KB、CHGMOD 5 0x4075 / 0xF2E8 Z80 ロゴ、15 色
YAZZIER.ROM 32 KB、ページ 1 から、CHGMOD 2 0x0391 / 0x2EFE R800 SCREEN 2 の文字
Dynamite Go! Go! 32 KB、CHGMOD 2 0x467B / 0xC5F3 Z80 120 フレームで題字。20 フレームでは黒。
c0man.rom 16 KB、BIOS の SCREEN 1 のまま 0x0345 / 0xF350 Z80 青一色。ネームは 0。スプライトは VRAM にあるが描かない。120 フレームでも BIOS の OTIR から出ない。
xracing_v1.0.4.rom 48 KB、ページ 0 から。$4000 の AB、初期化 0x4010 0x19B6 / 0xEA90 Z80 黒。LDIR までは SP 0xF37C。その後スタックが壊れる。
Bad Apple (ASCII16) 2 MB、ホスト側 ASCII16。初期化 0x4810 0x0039、SP が流れ続ける Z80 黒。$0038 のベクタ JP を繰り返し引退する。
BULLRUSH.ROM 1 MB、ASCII16、R800 0xEC00 / 0xF2FC 緑一色。ネームテーブルは「C-BIOS」。SCREEN 0 をまだ走査しない。
AUREL_VAULT.rom 1 MB、ASCII16、R800 0x8D94 / 0xF2FA 緑一色。VRAM は埋まっている。モードは 1 / 2 / 5 ではない。
btron8.rom MegaROM、R800 0xFF94 / 0xEFBB 黒
NIGHT_RAVEN_FLIGHT_DEMO MegaROM、R800 0xCC2F / 0xF2FA メニュー
NIGHT_RAVEN_GEO3D MegaROM、R800 0xEC60 / 0xF2FE 惑星
NEON_REVENANT 4 MB、ASCII16、R800 0x026B / 0xF2CD 暗い面。20 フレーム、SP は RAM の中。
assets/msx/ のディスク七枚（512 Bytes MSX1 Demo、An Uncle in Brazil、Audio Wave 3、Bad Apple Pyhesty、IOD GIF Demo、Puzzle Egg、Xmas Demo）は実行していない。FDC もディスク ROM も無い。ブートセクタを偽らない。
"Seven disk images stay on disk. There is no WD2793 and no disk ROM in bx8."
06 / Limits

6. まだ機械に無いもの (Not In This Machine)

Screen 0 · Sprites · IRQ Stack · No Bitstream

絵が平らな理由は、起動失敗とは別である。
"A flat frame can mean a missing scan mode. A smashed stack is a different bug. Neither has been patched by guessing."
項目 状態
SCREEN 0 モード 5'b00001 は R#7 の背景色で塗る。BULLRUSH の「C-BIOS」文字は VRAM にあり、画面には出ない。
スプライト モード 1 のスプライト走査は無い。c0man の青は、空のネームテーブルと未描画のスプライトの結果。
割り込みと SP Bad Apple は PC=0x0039 に張り付く。xracing は正常な LDIR のあと SP が RAM を離れる。原因は未確定。
ASCII16 バンク バンク切替はハーネスのホスト側。BSV のスロットマネージャはまだバンクを持たない。
OPLL / Geo3D / FDC OPLL.bsv も Geo3D.bsv もフロッピー制御も無い。
基板 ULX3S 用 Yosys スクリプトはある。ビットストリームは生成していない。焼いていない。
07 / Reproduce

7. 同じ絵を出す (Reproduce A Frame)

make run_rom · MSX_FRAMES · MSX_VRAM

デポのルートで。既定の ROM は assets/msx/MSX_LOGO.rom。
"The Makefile resolves the depot root from src/emulators/bx8/sim/verilator, five levels up. BIOS lookup walks the same distance."
make -C src/emulators/bx8/sim/verilator run_rom \
ROM="$(pwd)/assets/msx/MSX_LOGO.rom" \
PPM="$(pwd)/build/bx8/MSX_LOGO.ppm"
カートリッジ入場のあと何枚残すかは MSX_FRAMES（既定 20）。MSX_VRAM=1 はネーム、色、パターン、スプライト属性の非ゼロ数を出す。入場しなければ exit 2。PPM は失敗時も書く。
